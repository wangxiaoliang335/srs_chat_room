# 翻译文本服务接口说明

## 服务地址

| 环境 | HTTP API | WebSocket |
|------|----------|-----------|
| 生产环境 | `http://<服务器IP>:8085` | `ws://<服务器IP>:8086` |
| 本地开发 | `http://localhost:8085` | `ws://localhost:8086` |

---

## 一、WebSocket 实时接收（推荐）

### 1.1 连接地址

```
ws://<服务器地址>:8086/ws?user_id=<用户ID>&room_id=<房间ID>
```

**参数说明：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_id | string | 是 | 当前用户ID（接收方） |
| room_id | string | 否 | 房间ID |

**示例：**

```
ws://192.168.1.100:8086/ws?user_id=user_002&room_id=room_001
```

### 1.2 订阅消息

连接成功后，需要发送订阅消息：

```json
{
    "type": "subscribe",
    "data": {
        "user_id": "user_002",
        "room_id": "room_001"
    }
}
```

**订阅成功后，服务端返回：**

```json
{
    "type": "subscribed",
    "data": {
        "user_id": "user_002",
        "room_id": "room_001",
        "message": "Subscribed to translation texts"
    }
}
```

### 1.3 接收翻译文本

当有新的翻译文本时，服务端主动推送：

```json
{
    "type": "translation_text",
    "data": {
        "target_user": "user_002",
        "request_id": "a1b2c3d4-5678-90ab-cdef-1234567890ab",
        "room_id": "room_001",
        "source_user": "user_001",
        "original_text": "Hello everyone",
        "translated_text": "大家好",
        "source_lang": "en",
        "target_lang": "zh",
        "timestamp": 1714100000.123
    }
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| target_user | string | 接收方用户ID |
| source_user | string | 说话方用户ID |
| original_text | string | 原始语言文本 |
| translated_text | string | 翻译后文本 |
| source_lang | string | 源语言代码 |
| target_lang | string | 目标语言代码 |
| timestamp | float | 时间戳 |
| request_id | string | 请求唯一标识 |
| room_id | string | 房间ID |

### 1.4 接收原语音识别文本（可选）

如果需要同时接收原始语音识别结果：

```json
{
    "type": "original_speech_text",
    "data": {
        "room_id": "room_001",
        "source_user": "user_001",
        "original_text": "Hello everyone",
        "source_lang": "en",
        "timestamp": 1714100000.123
    }
}
```

### 1.5 心跳机制

客户端定期发送心跳：

```json
{
    "type": "ping"
}
```

服务端响应：

```json
{
    "type": "pong"
}
```

## 二、HTTP API 接口

### 2.1 健康检查

**请求：**

```
GET /health
```

**响应：**

```json
{
    "status": "ok",
    "service": "translation-text-server",
    "ws_clients": 5,
    "ws_users": 3,
    "ws_rooms": 2
}
```

### 2.2 查询翻译历史

**请求：**

```
GET /api/v1/translation/text/history?user_id=<用户ID>&limit=<条数>&offset=<偏移>
```

**参数说明：**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| user_id | string | 是 | - | 用户ID |
| limit | int | 否 | 100 | 查询条数 |
| offset | int | 否 | 0 | 偏移量 |

**响应：**

```json
{
    "code": 0,
    "data": {
        "texts": [
            {
                "original_text": "Hello",
                "translated_text": "你好",
                "source_lang": "en",
                "target_lang": "zh",
                "timestamp": 1714100000.123
            }
        ],
        "limit": 100,
        "offset": 0
    }
}
```

### 2.3 获取连接状态

**请求：**

```
GET /api/v1/translation/text/connections
```

**响应：**

```json
{
    "total_users": 5,
    "users": {
        "user_001": 2,
        "user_002": 1
    }
}
```

## 四、客户端接入示例

### 4.1 JavaScript 示例

```javascript
class TranslationClient {
    constructor(serverHost, userId, roomId) {
        this.serverHost = serverHost;
        this.userId = userId;
        this.roomId = roomId;
        this.ws = null;
        this.heartbeatTimer = null;
    }

    connect() {
        const wsUrl = `ws://${this.serverHost}/ws?user_id=${this.userId}&room_id=${this.roomId}`;
        console.log('Connecting to:', wsUrl);

        this.ws = new WebSocket(wsUrl);

        this.ws.onopen = () => {
            console.log('WebSocket connected');
            this.subscribe();
            this.startHeartbeat();
        };

        this.ws.onmessage = (event) => {
            const message = JSON.parse(event.data);
            this.onMessage(message);
        };

        this.ws.onerror = (error) => {
            console.error('WebSocket error:', error);
        };

        this.ws.onclose = () => {
            console.log('Disconnected, reconnecting...');
            this.stopHeartbeat();
            setTimeout(() => this.connect(), 3000);
        };
    }

    subscribe() {
        this.send({
            type: 'subscribe',
            data: {
                user_id: this.userId,
                room_id: this.roomId
            }
        });
    }

    send(data) {
        if (this.ws && this.ws.readyState === WebSocket.OPEN) {
            this.ws.send(JSON.stringify(data));
        }
    }

    startHeartbeat() {
        this.heartbeatTimer = setInterval(() => {
            this.send({ type: 'ping' });
        }, 30000); // 每30秒心跳一次
    }

    stopHeartbeat() {
        if (this.heartbeatTimer) {
            clearInterval(this.heartbeatTimer);
            this.heartbeatTimer = null;
        }
    }

    onMessage(message) {
        switch (message.type) {
            case 'connected':
                console.log('Service connected:', message.data.message);
                break;

            case 'subscribed':
                console.log('Subscribed successfully');
                break;

            case 'translation_text':
                this.onTranslationText(message.data);
                break;

            case 'original_speech_text':
                this.onOriginalSpeech(message.data);
                break;

            case 'cached_texts':
                // 处理离线缓存
                message.data.texts.forEach(text => this.onTranslationText(text));
                break;

            case 'pong':
                // 心跳响应
                break;

            default:
                console.log('Unknown message:', message.type);
        }
    }

    onTranslationText(data) {
        console.log('========================================');
        console.log(`说话人: ${data.source_user}`);
        console.log(`原文: ${data.original_text}`);
        console.log(`翻译: ${data.translated_text}`);
        console.log(`语言: ${data.source_lang} → ${data.target_lang}`);
        console.log('========================================');
    }

    onOriginalSpeech(data) {
        console.log(`[原语音] ${data.source_user}: ${data.original_text}`);
    }

    disconnect() {
        this.stopHeartbeat();
        if (this.ws) {
            this.ws.close();
        }
    }
}

// 使用示例
const client = new TranslationClient(
    '192.168.1.100:8086',  // WebSocket 服务器地址
    'user_002',             // 当前用户ID
    'room_001'              // 房间ID
);

client.connect();

// 页面关闭时断开连接
window.addEventListener('beforeunload', () => {
    client.disconnect();
});
```

### 4.2 Python 示例

```python
import asyncio
import json
import websockets
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class TranslationClient:
    def __init__(self, host: str, user_id: str, room_id: str = ''):
        self.host = host
        self.user_id = user_id
        self.room_id = room_id
        self.uri = f"ws://{host}/ws?user_id={user_id}&room_id={room_id}"

    async def connect(self):
        async with websockets.connect(self.uri) as ws:
            await self.subscribe(ws)

            async for message in ws:
                await self.handle_message(message)

    async def subscribe(self, ws):
        await ws.send(json.dumps({
            'type': 'subscribe',
            'data': {
                'user_id': self.user_id,
                'room_id': self.room_id
            }
        }))

    async def handle_message(self, message: str):
        try:
            data = json.loads(message)
            msg_type = data.get('type')
            msg_data = data.get('data', {})

            if msg_type == 'translation_text':
                self.on_translation(msg_data)
            elif msg_type == 'original_speech_text':
                self.on_original_speech(msg_data)
            elif msg_type == 'cached_texts':
                for text in msg_data.get('texts', []):
                    self.on_translation(text)
            elif msg_type in ('connected', 'subscribed'):
                logger.info(f"{msg_type}: {msg_data}")

        except json.JSONDecodeError:
            logger.error(f"Invalid JSON: {message}")

    def on_translation(self, data: dict):
        logger.info("=" * 40)
        logger.info(f"说话人: {data.get('source_user')}")
        logger.info(f"原文: {data.get('original_text')}")
        logger.info(f"翻译: {data.get('translated_text')}")
        logger.info(f"语言: {data.get('source_lang')} -> {data.get('target_lang')}")
        logger.info("=" * 40)

    def on_original_speech(self, data: dict):
        logger.info(f"[原语音] {data.get('source_user')}: {data.get('original_text')}")


async def main():
    client = TranslationClient(
        host='192.168.1.100:8086',  // WebSocket 服务器地址
        user_id='user_002',
        room_id='room_001'
    )

    try:
        await client.connect()
    except KeyboardInterrupt:
        logger.info("Disconnected")


if __name__ == '__main__':
    asyncio.run(main())
```

### 4.3 Flutter/Dart 示例

```dart
import 'dart:convert';
import 'dart:async';
import 'package:web_socket_channel/web_socket_channel.dart';

class TranslationClient {
  final String host;
  final String userId;
  final String roomId;
  
  WebSocketChannel? _channel;
  StreamSubscription? _subscription;
  final _translationController = StreamController<Map<String, dynamic>>.broadcast();

  Stream<Map<String, dynamic>> get onTranslation => _translationController.stream;

  TranslationClient({
    required this.host,
    required this.userId,
    this.roomId = '',
  });

  void connect() {
    final uri = Uri.parse('ws://$host/ws?user_id=$userId&room_id=$roomId');
    _channel = WebSocketChannel.connect(uri);

    _subscription = _channel!.stream.listen(
      _onMessage,
      onError: (error) => print('WebSocket error: $error'),
      onDone: () {
        print('WebSocket disconnected, reconnecting...');
        Future.delayed(Duration(seconds: 3), connect);
      },
    );

    _subscribe();
  }

  void _subscribe() {
    send({
      'type': 'subscribe',
      'data': {
        'user_id': userId,
        'room_id': roomId,
      }
    });
  }

  void send(Map<String, dynamic> data) {
    _channel?.sink.add(jsonEncode(data));
  }

  void _onMessage(dynamic message) {
    final data = jsonDecode(message as String);
    final type = data['type'] as String;
    final msgData = data['data'] as Map<String, dynamic>?;

    switch (type) {
      case 'translation_text':
        _translationController.add(msgData!);
        break;
      case 'connected':
      case 'subscribed':
        print('$type: ${msgData?['message']}');
        break;
    }
  }

  void disconnect() {
    _subscription?.cancel();
    _channel?.sink.close();
  }
}

// 使用示例
void main() {
  final client = TranslationClient(
    host: '192.168.1.100:8086',
    userId: 'user_002',
    roomId: 'room_001',
  );

  client.connect();

  client.onTranslation.listen((data) {
    print('说话人: ${data['source_user']}');
    print('原文: ${data['original_text']}');
    print('翻译: ${data['translated_text']}');
  });
}
```

### 4.4 Android/Kotlin 示例

```kotlin
import android.util.Log
import okhttp3.*
import java.util.concurrent.TimeUnit

class TranslationClient(
    private val host: String,
    private val userId: String,
    private val roomId: String
) {
    private var webSocket: WebSocket? = null
    private val client = OkHttpClient.Builder()
        .readTimeout(0, TimeUnit.MILLISECONDS)
        .build()

    fun connect() {
        val request = Request.Builder()
            .url("ws://$host/ws?user_id=$userId&room_id=$roomId")
            .build()

        webSocket = client.newWebSocket(request, object : WebSocketListener() {
            override fun onOpen(webSocket: WebSocket, response: Response) {
                Log.d(TAG, "WebSocket connected")
                subscribe()
            }

            override fun onMessage(webSocket: WebSocket, text: String) {
                handleMessage(text)
            }

            override fun onFailure(e: Throwable, response: Response?) {
                Log.e(TAG, "WebSocket error: ${e.message}")
                // 重连
                android.os.Handler(android.os.Looper.getMainLooper()).postDelayed({
                    connect()
                }, 3000)
            }
        })
    }

    private fun subscribe() {
        val message = """
            {
                "type": "subscribe",
                "data": {
                    "user_id": "$userId",
                    "room_id": "$roomId"
                }
            }
        """.trimIndent()
        webSocket?.send(message)
    }

    private fun handleMessage(text: String) {
        val json = JSONObject(text)
        val type = json.getString("type")
        val data = json.optJSONObject("data")

        when (type) {
            "translation_text" -> {
                val sourceUser = data?.getString("source_user")
                val originalText = data?.getString("original_text")
                val translatedText = data?.getString("translated_text")
                
                Log.d(TAG, "翻译: [$sourceUser] $originalText -> $translatedText")
            }
        }
    }

    fun disconnect() {
        webSocket?.close(1000, "Client closed")
    }

    companion object {
        private const val TAG = "TranslationClient"
    }
}
```

## 六、注意事项

1. **连接保活**：建议客户端实现自动重连机制，网络断开后自动重连
2. **心跳**：建议每30秒发送一次心跳，保持连接活跃
3. **离线消息**：用户重新连接后会收到 `cached_texts` 消息，包含离线期间的翻译文本
4. **编码**：所有文本使用 UTF-8 编码
5. **安全**：生产环境建议添加认证机制（可在后续版本中实现）
