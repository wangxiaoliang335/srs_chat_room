# 翻译文本推送失败问题说明

## 问题描述

**推送翻译文本到客户端失败**，表现为：
- 音频翻译服务成功调用百度实时翻译API并获得翻译结果
- 但翻译文本无法成功推送到客户端

## 技术架构分析

### 当前推送流程

```
┌─────────────────────────────────────────────────────────────────────────┐
│                          翻译文本推送流程                                  │
└─────────────────────────────────────────────────────────────────────────┘

用户说话
    │
    ▼
┌─────────────────────────────────────────────┐
│  audio_translation_service_websocket.py     │
```

### 关键代码位置

**音频翻译服务推送代码** (`audio_translation_service_websocket.py` 第215-243行):

```python
def _push_translation_text(self, original_text: str, translated_text: str,
                           from_lang: str, to_lang: str):
    """推送翻译文本给客户端"""
    target_user = os.getenv("TARGET_USER", "")
    room_id = os.getenv("ROOM_ID", "")
    text_server_url = os.getenv("TEXT_SERVER_URL", "http://localhost:8086")

    if not target_user:
        return

    try:
        push_url = f"{text_server_url}/api/v1/translation/text/push"
        data = {
            "target_user": target_user,
            "request_id": self.request_id,
            "room_id": room_id,
            "source_user": os.getenv("SOURCE_USER", ""),
            "original_text": original_text,
            "translated_text": translated_text,
            "source_lang": from_lang,
            "target_lang": to_lang,
            "timestamp": time.time()
        }

        response = requests.post(push_url, json=data, timeout=3)
        if response.status_code == 200:
            logger.debug(f"[{self.request_id}] Pushed translation text")
    except Exception as e:
        logger.warning(f"[{self.request_id}] Failed to push translation text: {e}")
```

## 可能失败原因

### 1. 翻译文本推送服务未启动

**症状**: `requests.post()` 抛出 `ConnectionRefusedError`

**排查命令**:
```bash
# 检查服务是否运行
ps aux | grep translation_text_publisher
netstat -tlnp | grep 8086

# 查看日志
tail -f translation_text_publisher.log
```

**解决**: 启动翻译文本推送服务
```bash
cd /root/srs-project/srs
python translation_text_publisher.py &
```

### 2. 目标用户未设置或为空

**症状**: `target_user` 环境变量未设置，导致 POST 请求返回 400 错误

**排查**: 检查日志中是否有 `Missing target_user` 错误

**解决**: 确保启动音频翻译服务时设置 `TARGET_USER` 环境变量
```bash
export TARGET_USER="user_B"
export ROOM_ID="room1"
export SOURCE_USER="user_A"
python audio_translation_service_websocket.py
```

### 3. 客户端未连接 WebSocket

**症状**: HTTP POST 成功返回 200，但客户端收不到消息

**原因**: 翻译文本已推送到服务端，但目标用户的 WebSocket 客户端未连接

**解决**: 客户端需要先建立 WebSocket 连接并订阅

### 4. WebSocket 推送失败

**症状**: 服务端日志显示推送失败

**排查**: 检查 `translation_text_publisher.py` 第330-345行的推送逻辑

```python
def push_translation_text(self, user_id: str, text_data: dict):
    # ...
    try:
        client_ids = list(self.user_connections.get(user_id, set()))
        for client_id in client_ids:
            if client_id in self.clients:
                message = {
                    'type': MessageType.TRANSLATION_TEXT,
                    'data': text_data
                }
                asyncio.run(self._send(self.clients[client_id], message))
    # ...
```

**可能原因**:
- `user_connections` 中没有该用户
- WebSocket 连接已断开

## 客户端接收翻译文本的方法

### 方法一：原生 WebSocket 连接（推荐）

```javascript
class TranslationTextClient {
    constructor(serverUrl, userId, roomId = '') {
        this.serverUrl = serverUrl;
        this.userId = userId;
        this.roomId = roomId;
        this.ws = null;
    }

    connect() {
        // 建立 WebSocket 连接
        let wsUrl = `${this.serverUrl}/ws?user_id=${this.userId}`;
        if (this.roomId) {
            wsUrl += `&room_id=${this.roomId}`;
        }

        console.log(`Connecting to: ${wsUrl}`);
        this.ws = new WebSocket(wsUrl);

        this.ws.onopen = () => {
            console.log('Connected to translation text service');

            // 发送订阅消息
            this.subscribe(this.userId, this.roomId);
        };

        this.ws.onmessage = (event) => {
            try {
                const message = JSON.parse(event.data);
                this.handleMessage(message);
            } catch (e) {
                console.error('Failed to parse message:', e);
            }
        };

        this.ws.onerror = (error) => {
            console.error('WebSocket error:', error);
        };

        this.ws.onclose = () => {
            console.log('Disconnected, reconnecting in 3s...');
            setTimeout(() => this.connect(), 3000);
        };
    }

    subscribe(userId, roomId) {
        if (this.ws && this.ws.readyState === WebSocket.OPEN) {
            this.ws.send(JSON.stringify({
                type: 'subscribe',
                data: {
                    user_id: userId,
                    room_id: roomId || ''
                }
            }));
        }
    }

    handleMessage(message) {
        console.log('Received message:', message.type);

        switch (message.type) {
            case 'connected':
                console.log('Connected:', message.data.message);
                break;

            case 'subscribed':
                console.log('Subscribed:', message.data);
                break;

            case 'cached_texts':
                // 接收离线缓存的翻译文本
                console.log(`Received ${message.data.count} cached texts`);
                message.data.texts.forEach(text => {
                    this.displayTranslation(text);
                });
                break;

            case 'translation_text':
                // 接收实时翻译文本
                console.log('Translation:', message.data);
                this.displayTranslation(message.data);
                break;

            case 'original_speech_text':
                // 接收原始语音识别文字
                console.log('Original Speech:', message.data.original_text);
                break;

            case 'pong':
                // 心跳响应
                break;

            case 'error':
                console.error('Error:', message.data.message);
                break;

            default:
                console.log('Unknown message type:', message.type);
        }
    }

    displayTranslation(data) {
        // 在页面上显示翻译结果
        const translationDiv = document.getElementById('translations');
        if (translationDiv) {
            const item = document.createElement('div');
            item.className = 'translation-item';
            item.innerHTML = `
                <div class="speaker">${data.source_user}</div>
                <div class="original">${data.original_text}</div>
                <div class="translated">${data.translated_text}</div>
                <div class="meta">${data.source_lang} → ${data.target_lang}</div>
            `;
            translationDiv.appendChild(item);
        }

        // 打印到控制台
        console.log(`[${data.source_user}] ${data.original_text} → ${data.translated_text}`);
    }

    disconnect() {
        if (this.ws) {
            this.ws.close();
            this.ws = null;
        }
    }
}

// 使用示例
const client = new TranslationTextClient(
    'ws://localhost:8086',  // 服务器地址
    'user_B',               // 当前用户ID（接收方）
    'room1'                 // 房间ID
);
client.connect();
```

### 方法二：Python 客户端

```python
import asyncio
import json
import websockets
import logging

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


class TranslationClient:
    def __init__(self, server_url: str, user_id: str, room_id: str = ''):
        self.server_url = server_url
        self.user_id = user_id
        self.room_id = room_id
        self.ws = None

    async def connect(self):
        # 构建 WebSocket URL
        ws_url = f"{self.server_url}/ws?user_id={self.user_id}"
        if self.room_id:
            ws_url += f"&room_id={self.room_id}"

        logger.info(f"Connecting to {ws_url}")

        async with websockets.connect(ws_url) as ws:
            self.ws = ws
            await self.subscribe()

            async for message in ws:
                await self.handle_message(message)

    async def subscribe(self):
        await self.ws.send(json.dumps({
            'type': 'subscribe',
            'data': {
                'user_id': self.user_id,
                'room_id': self.room_id
            }
        }))

    async def handle_message(self, message_str: str):
        try:
            message = json.loads(message_str)
            msg_type = message.get('type')
            data = message.get('data', {})

            if msg_type == 'translation_text':
                logger.info(f"Translation: [{data.get('source_user')}] "
                           f"{data.get('original_text')} → {data.get('translated_text')}")

            elif msg_type == 'cached_texts':
                logger.info(f"Received {data.get('count')} cached translations")
                for text in data.get('texts', []):
                    logger.info(f"  - {text.get('original_text')} → {text.get('translated_text')}")

            elif msg_type == 'connected':
                logger.info(f"Connected: {data.get('message')}")

            elif msg_type == 'subscribed':
                logger.info(f"Subscribed: user={data.get('user_id')}, room={data.get('room_id')}")

            else:
                logger.debug(f"Received: {msg_type}")

        except json.JSONDecodeError:
            logger.error(f"Invalid JSON: {message_str}")


async def main():
    client = TranslationClient(
        server_url='ws://localhost:8086',
        user_id='user_B',  # 接收方用户ID
        room_id='room1'
    )

    try:
        await client.connect()
    except KeyboardInterrupt:
        logger.info("Disconnected by user")


if __name__ == '__main__':
    asyncio.run(main())
```
