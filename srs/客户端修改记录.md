## v1 · 音频格式重采样（2026-05-17）

### 修改文件清单

#### 1. `electron/main.ts` — 核心修改

**接口参数更新**：

```typescript
interface FFmpegStreamConfig {
  rtmpUrl: string;
  inputSampleRate?: number;   // 输入音频的实际采样率（默认 44100）
  inputChannels?: number;     // 输入音频的实际声道数（默认 2）
  outputSampleRate?: number;  // 期望输出的采样率（默认 16000）
  outputChannels?: number;    // 期望输出的声道数（默认 1）
  bitrate?: string;
}
```

**FFmpeg 参数添加音频过滤器**：

```javascript
'-af', `aresample=${outputSampleRate}:filter_size=64:cutoff=0.95`,
'-ac', outputChannels.toString(),
'-profile:a', 'aac_low',  // AAC-LC 配置文件，兼容性更好
```

#### 2. `electron/preload.ts` — 接口类型同步更新

接口类型与 main.ts 保持一致。

#### 3. `AudioStream.ts` — 调用参数更新

| 场景 | inputSampleRate | outputSampleRate | 说明 |
|------|-----------------|------------------|------|
| MP3 文件 | audioBuffer.sampleRate (如 44100) | 16000 | 使用 MP3 实际采样率 |
| 麦克风 | audioContext.sampleRate (如 48000) | 16000 | 使用 AudioContext 采样率 |

### 修复效果

**音频重采样流程**：

```
输入: 44100Hz 立体声 PCM
  ↓ FFmpeg 重采样 (aresample + pan)
输出: 16000Hz 单声道 AAC → RTMP 流
```

**预期结果**：

- [x] SRS 服务器接收到的音频应为 16kHz 单声道
- [x] `decodedFrames` 应大于 0
- [x] flv.js 可正常解码播放

### 待验证（v1）

请在客户端重新测试：

1. SRS 服务器检测到的音频格式是否为 **16kHz 单声道**
2. `decodedFrames` 是否大于 0
3. 音频是否能正常播放

## v2 · 接入 JWT（2026-07-12，已生效）

所有 `/api/v1/*` 业务接口必须携带 `Authorization: Bearer <jwt>`；用户身份以 `user_id`（`user_<hex12>`）为准；owner/admin 角色可用于后台管理。详见 `客户端_API_鉴权文档.md`。
